# Defender XRay

A Chromium browser extension for investigating **Microsoft Graph API calls** issued by the [Defender XDR portal](https://security.microsoft.com).  Open your browser's developer tools, navigate to the **Defender XRay** panel, and every Graph API request the portal makes will be captured, displayed, and converted into a ready-to-run code snippet — perfect for understanding, reproducing, or automating Defender XDR workflows.

---

## Features

| Feature | Details |
|---|---|
| **API Call Inspection** | Captures every `GET`, `POST`, `PATCH`, `PUT`, and `DELETE` request to `graph.microsoft.com` |
| **Full Request / Response** | View headers and body for both the request and the response |
| **Instant Code Generation** | One click converts any captured call into a runnable script |
| **Multi-Language Support** | PowerShell · Python · C# · JavaScript |
| **Export** | Download all captured calls as a single JSON file |
| **Pause / Resume** | Toggle recording at any time without closing DevTools |

### Supported output languages

| Language | SDK / Library |
|---|---|
| **PowerShell** | [Microsoft Graph PowerShell SDK](https://learn.microsoft.com/en-us/powershell/microsoftgraph/) — `Invoke-MgGraphRequest` |
| **Python** | [`requests`](https://docs.python-requests.org/) + [`msal`](https://github.com/AzureAD/microsoft-authentication-library-for-python) |
| **C#** | `HttpClient` + [`Azure.Identity`](https://learn.microsoft.com/en-us/dotnet/azure/sdk/authentication/) |
| **JavaScript** | [Microsoft Graph JavaScript SDK](https://github.com/microsoftgraph/msgraph-sdk-javascript) + [`@azure/identity`](https://github.com/Azure/azure-sdk-for-js/tree/main/sdk/identity/identity) |

## Installation

The extension is loaded as an **unpacked extension** — no Chrome Web Store listing required.

1. **Clone or download** this repository.

2. Open Chrome (or any Chromium-based browser) and navigate to  
   `chrome://extensions`

3. Enable **Developer mode** (toggle in the top-right corner).

4. Click **Load unpacked** and select the `extension/` folder inside this repository.

5. The extension is now installed.  You will see the **Defender XRay** icon in the Chrome toolbar.

---

## Usage

1. Open (or navigate to) the **Defender XDR portal** — `https://security.microsoft.com` — in a tab.

2. Open **Chrome DevTools** in that tab (`F12` or `Ctrl+Shift+I` / `Cmd+Option+I`).

3. Click the **Defender XRay** tab in the DevTools toolbar.

4. Browse the Defender XDR portal normally.  Every Graph API call will appear as a row in the panel.

5. **Click any row** to inspect it:
   - **Overview** — URL, method, status, duration, API version
   - **Request** — headers and body sent to the Graph API
   - **Response** — headers and body returned by the Graph API
   - **Code** — generated script in your chosen language

6. Use the **language dropdown** in the Code tab to switch between PowerShell, Python, C#, and JavaScript.

7. Click **Copy** to copy the snippet to your clipboard.

8. Click **Export JSON** to download all captured requests as a JSON file.

9. Click the **● Recording** button to pause/resume capture.

10. Click **Clear** to reset the list.

> **Tip** — Open DevTools _before_ loading a Defender XDR page to capture requests made during initial page load.

## Generated code examples

### PowerShell
```powershell
# Generated by Defender XRay
# GET https://graph.microsoft.com/v1.0/security/incidents

# Prerequisites
#   Install-Module Microsoft.Graph -Scope CurrentUser

# Connect to Microsoft Graph (interactive, browser-based login).
Connect-MgGraph

# GET /v1.0/security/incidents
$response = Invoke-MgGraphRequest `
    -Method GET `
    -Uri "https://graph.microsoft.com/v1.0/security/incidents" `
    -OutputType PSObject

# Display the response
$response | ConvertTo-Json -Depth 10
```

### Python
```python
# Generated by Defender XRay
# GET https://graph.microsoft.com/v1.0/security/incidents

# Prerequisites
#   pip install requests msal

import requests
import msal

TENANT_ID     = "YOUR_TENANT_ID"
CLIENT_ID     = "YOUR_CLIENT_ID"
CLIENT_SECRET = "YOUR_CLIENT_SECRET"

app = msal.ConfidentialClientApplication(
    CLIENT_ID,
    authority=f"https://login.microsoftonline.com/{TENANT_ID}",
    client_credential=CLIENT_SECRET,
)

token_response = app.acquire_token_for_client(
    scopes=["https://graph.microsoft.com/.default"]
)

headers = {
    "Authorization": f"Bearer {token_response['access_token']}",
    "Content-Type": "application/json",
}

url = "https://graph.microsoft.com/v1.0/security/incidents"
response = requests.get(url, headers=headers)
response.raise_for_status()
print(response.json())
```

### C#
```csharp
// Generated by Defender XRay
// GET https://graph.microsoft.com/v1.0/security/incidents

// Prerequisites (NuGet packages)
//   dotnet add package Azure.Identity

using Azure.Core;
using Azure.Identity;
using System.Net.Http;
using System.Net.Http.Headers;

var tenantId     = "YOUR_TENANT_ID";
var clientId     = "YOUR_CLIENT_ID";
var clientSecret = "YOUR_CLIENT_SECRET";

var credential = new ClientSecretCredential(tenantId, clientId, clientSecret);
var tokenRequest = new TokenRequestContext(
    new[] { "https://graph.microsoft.com/.default" }
);
var token = await credential.GetTokenAsync(tokenRequest);

using var httpClient = new HttpClient();
httpClient.DefaultRequestHeaders.Authorization =
    new AuthenticationHeaderValue("Bearer", token.Token);

var url = "https://graph.microsoft.com/v1.0/security/incidents";
var response = await httpClient.GetAsync(url);
response.EnsureSuccessStatusCode();

var responseBody = await response.Content.ReadAsStringAsync();
Console.WriteLine(responseBody);
```

### JavaScript
```javascript
// Generated by Defender XRay
// GET https://graph.microsoft.com/v1.0/security/incidents

// Prerequisites (npm packages)
//   npm install @microsoft/microsoft-graph-client @azure/identity

import { Client } from "@microsoft/microsoft-graph-client";
import { ClientSecretCredential } from "@azure/identity";
import { TokenCredentialAuthenticationProvider }
    from "@microsoft/microsoft-graph-client/authProviders/azureTokenCredentials";

const tenantId     = "YOUR_TENANT_ID";
const clientId     = "YOUR_CLIENT_ID";
const clientSecret = "YOUR_CLIENT_SECRET";

const credential = new ClientSecretCredential(tenantId, clientId, clientSecret);
const authProvider = new TokenCredentialAuthenticationProvider(credential, {
    scopes: ["https://graph.microsoft.com/.default"],
});
const client = Client.initWithMiddleware({ authProvider });

const result = await client.api(`/v1.0/security/incidents`).get();
console.log(JSON.stringify(result, null, 2));
```

## Privacy & security

- The extension only reads network traffic **already visible** in the DevTools Network tab.
- It does **not** send any data to external servers.
- Authorization header values are **redacted** (`Bearer [REDACTED]`) in the Request/Response header display to prevent accidental token leakage in screenshots.
- Generated code snippets use **placeholder** credential values (`YOUR_TENANT_ID`, etc.) — they never embed the captured token.
